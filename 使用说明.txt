听转 · 批量音频转换器 1.0
Windows 10 / 11 64 位免安装程序

使用
1. 双击“听转音频转换器.exe”。不需要安装 Python 或 FFmpeg。
2. 拖入文件或文件夹，或点击“添加文件”“添加文件夹”。文件夹会递归扫描子文件夹。
3. 选择输出目录和 MP3 品质，点击“开始批量转换”。
4. 完成后点击“打开输出目录”；失败项目可双击查看具体原因，也可导出记录。

支持输入
.ncm、.flac、.wav、.mp3、.m4a、.aac、.ogg、.opus、.wma、.aiff、.aif、.ape。
具体可解码内容取决于文件本身；不支持网易云缓存分片、下载不完整的文件或仅改扩展名的文件。

品质与文件保护
- 默认 V0 高品质，可选 320 / 192 / 128 kbps。
- 已有 MP3 和 NCM 内原本为 MP3 的音频直接复制音频流，不重复压缩；品质选项对此类文件不生效。
- FLAC、WAV 等转为 MP3 属于有损转码，不能提高原音频质量。
- 尽量保留可识别的标题、歌手和专辑文字标签；此版本不保留封面、歌词和其他非音频轨道。
- 原文件不会修改或删除。输出重名自动增加“(1)”等编号，不覆盖已有文件。
- 转换失败或停止时会清理未完成输出；此前已完成的 MP3 会保留。
- 再次点击开始会重新处理整个列表；需要时可先移除已完成项目。

运行方式
所有音频处理在本机完成，不上传音频，不需要登录网易云账号。
首次开始时会在 Windows 临时目录展开内置转换引擎，随后离线使用。
本程序尚未进行数字签名。

验证范围
通过了 WAV/FLAC 转码、MP3 音频流保持、NCM MP3/FLAC 容器、中文路径、封面预留区、重名保护、损坏文件隔离和取消清理等测试。
已检查原生界面启动，以及打包后转换引擎的实际输出播放解码。
NCM 使用自行生成的测试样本验证，未使用你的真实歌曲；不保证所有未来的 NCM 格式变体均兼容。

源码与组件许可见“源码”和“licenses”目录。仅处理你有权转换的音频。
